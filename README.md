# 🚗 RoadGuard — AI-Powered Pothole Detection & Road Safety System

RoadGuard is an intelligent road safety project designed to detect potholes using artificial intelligence, computer vision, and deep learning.

The system uses **YOLO11n** for pothole detection from road images and videos, along with **ByteTrack** for tracking detected potholes across consecutive frames.

RoadGuard aims to go beyond traditional pothole detection by introducing a **pothole memory system** that stores previously detected road hazards and warns approaching vehicles about potential dangers, including potholes hidden by rainwater.

### Key Features
- AI-based pothole detection using YOLO11n
- Road image and video processing
- Real-time object detection capabilities
- Pothole tracking using ByteTrack
- GPU-supported model training and evaluation
- Planned pothole location storage and mapping
- Planned vehicle-to-vehicle warning system
- Planned automatic pothole re-verification

### Technologies Used
**Python | YOLO11n | Ultralytics | PyTorch | OpenCV | ByteTrack | Google Colab**

### Current Development Status
The AI model has been trained and evaluated, and video-based pothole detection and object tracking have been implemented. Further development focuses on improving detection reliability and integrating pothole memory, location-based warnings, and hardware demonstrations.

### Project Goal
To improve road safety by developing an intelligent system that can **detect, remember, and communicate pothole information to approaching vehicles**.
